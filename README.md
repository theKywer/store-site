# 🌙 Luna Market

**Luna Market** — full-stack интернет-магазин цифровых видеоигр с каталогом, поиском, фильтрацией, корзиной, авторизацией пользователей, оформлением заказов и административной панелью.

Проект разработан в образовательных целях для изучения современной веб-разработки, React, Node.js, Express и работы с базами данных.

## ✨ Возможности

### 🛒 Магазин
- Каталог видеоигр.
- Отдельные страницы с подробной информацией об играх.
- Галерея изображений и видео.
- Поиск по названию, жанру и описанию.
- Фильтрация по жанрам и возрастному рейтингу.
- Сортировка по цене и названию.
- Адаптивный интерфейс.
- Избранное.
- Уведомления о действиях пользователя.

### 🛍 Корзина и заказы
- Добавление игр в корзину.
- Изменение количества товаров и удаление из корзины.
- Автоматический расчёт стоимости заказа.
- Сохранение корзины в `localStorage`.
- Оформление заказов.
- Демонстрационная оплата без списания реальных денег.
- Генерация уникальных демонстрационных ключей формата `XXXX-XXXX`.
- История заказов пользователя.
- Просмотр приобретённых игр и выданных ключей.

### 🔐 Авторизация
- Регистрация и вход пользователей.
- Хеширование паролей с помощью bcrypt.
- JWT-аутентификация.
- Роли пользователей `USER` и `ADMIN`.
- Защита маршрутов и административных функций.

### ⚙️ Административная панель
- Добавление новых игр.
- Редактирование информации об играх.
- Удаление игр.
- Управление галереей изображений и видео.
- Просмотр заказов.
- Просмотр информации о покупателях.
- Управление статусами заказов.
- Просмотр выданных демонстрационных ключей.

## 🔌 Основные API-маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/games` | Получение каталога |
| GET | `/games/:id` | Получение игры |
| POST | `/auth/register` | Регистрация |
| POST | `/auth/login` | Авторизация |
| POST | `/games` | Добавление игры |
| PATCH | `/games/:id` | Редактирование игры |
| DELETE | `/games/:id` | Удаление игры |
| POST | `/orders` | Создание заказа |
| POST | `/orders/:id/pay` | Демонстрационная оплата |
| GET | `/orders/my` | История заказов |
| GET | `/admin/orders` | Просмотр всех заказов |

Административные маршруты и операции с заказами защищены авторизацией и проверкой прав доступа.

## 📌 Статус проекта

Основной функционал магазина реализован.

Проект включает frontend, backend, базу данных, авторизацию, управление каталогом, оформление заказов и административную панель.

Оплата является демонстрационной: реальные денежные средства не списываются, а выдаваемые ключи сгенерированы для демонстрации работы магазина и не являются настоящими ключами активации игр.
